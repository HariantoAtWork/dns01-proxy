# Fixed multi-host proxy stalls and stale SNI

Health probes now cancel unread response bodies and validate empty forward hosts so parallel checks no longer pin Bun fetch sockets. Edge HTTPS/SNI reloads when Proxy Hosts are saved; wildcard domains expand to exact cert SANs instead of a literal `*.` serverName. HTTPS upstreams skip cert verify like health probes, and host health loads with bounded concurrency.
