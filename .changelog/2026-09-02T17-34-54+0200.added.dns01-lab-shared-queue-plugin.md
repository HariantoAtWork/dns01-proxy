# DNS-01 lab plugin with shared queue

Added `plugins/dns01-lab` — a certs-page clone for reachability testing using `lab-domain.txt`.

Lab runs share the certificate job queue (`source: lab`) so Apply and lab never publish TXT concurrently. Real steps: DNS preflight, Publish TXT, TXT online, DNS settle. Faked steps: FAKE ACME order (local token generation) and FAKE LE validate (no Let's Encrypt calls).

New route `/lab`, APIs under `/api/lab/*`, and sidebar link. Certificate queue UI shows lab jobs as `#N lab`.
