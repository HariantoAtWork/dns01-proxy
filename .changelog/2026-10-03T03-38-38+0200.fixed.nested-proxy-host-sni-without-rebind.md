# Nested Proxy Hosts no longer need :443 rebind

Names like `test.admin.harianto.dev` do not match Bun’s one-label `*.harianto.dev` SNI. The edge previously registered each exact nested name, so every new admin host changed the TLS fingerprint and forced a rebind (and a restart when that rebind failed).

SNI now prefers the covering parent wildcard from the live cert (`*.admin.harianto.dev`). Further nested hosts under the same parent share that SNI set, so the route table hot-swaps and HTTPS works without rebinding or restarting the container.
