# Clarify SSL Certificate toggle (keep current HTTPS behaviour)

The SSL Certificate checkbox was easy to read as “HTTP-only when off”, like Nginx Proxy Manager. Runtime stays as-is: Off turns off SSL features for that host; a covering zone/wildcard cert on :443 may still serve HTTPS.

Status line and info drawer now say that explicitly. HTTP/2 no longer defaults to on when SSL Certificate is off, so the SSL tab matches the real meaning of the toggle.
