# Rebind edge HTTPS when SNI names change

Bun.serve().reload() never registers newly added TLS serverNames, so a new SSL Proxy Host (e.g. markdown-to-cv.admin.harianto.link) kept the auth-zone default leaf (mizu.work) until a container restart. Names-only SNI updates now drain and rebind :443 like PEM renewals, instead of hot-reload.
