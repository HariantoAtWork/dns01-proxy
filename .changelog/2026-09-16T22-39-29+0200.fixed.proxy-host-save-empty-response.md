Saving a Proxy Host no longer force-closes edge HTTPS mid-request (graceful drain + deferred SNI rebind), which stopped `PUT /api/proxy/hosts` from dying as `net::ERR_EMPTY_RESPONSE` when the auth UI rides edge `:443`. Control-plane idleTimeout now defaults to 120s like edge so `/api/certs/stream` is less likely to end as incomplete chunked encoding.
