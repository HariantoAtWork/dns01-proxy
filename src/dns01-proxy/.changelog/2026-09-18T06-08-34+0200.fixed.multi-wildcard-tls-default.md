# Pick a real wildcard as TLS default when several exist

With multiple SSL catch-all wildcards (e.g. `*.uti.email` and `*.harianto.link`), Bun only allows one no-SNI default. We previously fell back to the auth-zone cert, so names like `spark.uti.email` that only match `*.uti.email` (not listed as exact domainNames) got the wrong leaf (`mizu.work`). The default is now the wildcard cert that already covers the most exact Proxy Host names; other zones still need exact domainNames for reliable SNI.
